# Enterprise Network Design — Contoso Academic Group Project

**Type:** Academic group network-design assignment  
**Contributor:** Bhargav Gosai (group project)

## Objective
Propose a resilient and scalable network design for a fictional online-store organization with headquarters and a branch location.

## Design considerations
- Redundant network links and devices to reduce single points of failure
- IPv4 addressing and subnet planning for different device populations
- Growth capacity, quality-of-service considerations and bandwidth allocation
- Proposed firewalls, VPN remote access, access controls, and intrusion detection/prevention

## Skills demonstrated
Network topology · IPv4 subnetting · Redundancy · VPN concepts · ACLs · Network security · QoS
