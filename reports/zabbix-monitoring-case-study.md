# Zabbix Network Monitoring — Linux and Windows Lab

**Type:** Educational monitoring lab  
**Author:** Bhargav Gosai

## Objective
Deploy Zabbix and monitor a Windows Server 2019 machine from a Linux-based monitoring server.

## Implementation
- Configured an Ubuntu Server virtual machine, SSH access and a MySQL backend
- Installed Zabbix server, frontend and monitoring components
- Set up a Windows Server 2019 virtual machine as a monitored host
- Used HeavyLoad to generate test load and observed monitoring behavior

## Skills demonstrated
Zabbix · Ubuntu Server · Windows Server 2019 · MySQL · SSH · Virtualization · Infrastructure monitoring

**Publication note:** Recruiter-facing summary of a documented lab, not a claim of enterprise production monitoring.
