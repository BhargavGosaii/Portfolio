# Splunk SIEM and Log Forwarding — Ubuntu Lab

**Type:** Educational infrastructure/security lab  
**Author:** Bhargav Gosai

## Objective
Configure centralized log collection and demonstrate searchable event ingestion.

## Implementation
- Prepared two Ubuntu virtual machines on a shared virtual network
- Installed Splunk Enterprise on the receiving server
- Configured the receiving port and installed Splunk Universal Forwarder on the source machine
- Forwarded logs to the indexer and used the Splunk search/reporting interface to inspect collected data

## Skills demonstrated
Splunk Enterprise · Splunk Universal Forwarder · Ubuntu · Linux CLI · Log forwarding · SIEM fundamentals · Virtual machines
